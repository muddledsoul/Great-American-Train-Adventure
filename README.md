# The Great American Railway

A live map of the Amtrak network. Click any line to see its stops and the trains running it right now, pull a departure board for any station and date, search city to city, and jump straight to Amtrak.com or the Amtrak app to book.

No backend, no build step: one HTML file pulling the [Amtraker](https://amtraker.com) live feed and USDOT/FRA route geometry. Served from GitHub Pages; installs to an iPhone or Android home screen as a web app.

Not affiliated with Amtrak. Confirm times on Amtrak.com before you travel.
